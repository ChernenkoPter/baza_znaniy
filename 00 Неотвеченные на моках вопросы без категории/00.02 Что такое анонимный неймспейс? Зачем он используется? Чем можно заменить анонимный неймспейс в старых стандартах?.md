- `[inline] namespace { namespace-body }` - это синтаксический сахар для
```
[inline] namespace unique { /* empty body */ } // unique - уникальный внутри единицы трансляции
using namespace unique;
namespace unique { namespace-body }
```
- как и обычные неймспейсы поддерживают переоткрытие, вложенность, отделяют содержимое от остальноq программы визуально
  - не требуют `using namespace unique` (он неявный) или `uniqie::X` для unqualified lookup в объемлющем неймспейсе
- имеют internal linkage, в других единицах трансляции не видны
- Были добавлены в 98 стандарте, до этого можно было использовать static функции и переменные
  - Ключевое слово static имеет несколько значений в зависимости от контекста, поэтому линтеры рекомендуют использовать анонимные неймспейсы
