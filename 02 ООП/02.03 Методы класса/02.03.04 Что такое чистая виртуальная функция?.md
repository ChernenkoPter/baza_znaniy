Это виртуальный метод, который объявлен `= 0`.
При наличии хоть одной такой функии класс становится абстрактным - запрещается его инстанцирование.
Однако стандарт разрешает определить чистую виртуальную функцию для базового класса вне его объявления:
```
class MyClass { 
    virtual void ok() = 0;
//    virtual void not_ok() = 0 {...}; // запрещено стандартом - https://timsong-cpp.github.io/cppwp/n4861/class.abstract#2.note-3
};
void MyClass::ok() {...}
```
