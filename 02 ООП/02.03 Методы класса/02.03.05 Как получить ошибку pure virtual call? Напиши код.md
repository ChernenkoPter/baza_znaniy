Pure virtual call - это вызов чистой виртуальной функции в констуркторе или деструкторе абстрактного базового класса (во время вызова конструктора или деструктора производного класса), это UB. 

Многие компиляторы вместо адреса чистой виртуальной функции в vtable базового класса вставляют адрес функции-заглушки, которая вызывет **std::terminate**
```
struct A { A() {f();}   virtual void f() = 0; }; // или ~A() { f(); }
struct B : A {};
{
    B b; // ошибка здесь, если вызов в конструкторе
} // ошибка здесь, если вызов в деструкторе
```
