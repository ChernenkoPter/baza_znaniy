При написании класса надо придерживаться одного из 3 правил:
- Правило 5 - требуется определить все 5 методов, если определен хоть 1 из них: деструктор, конструктор копирования и перемещения, копирующий и перемещающий оператор присваивания
- Правило 3 - то же, но для деструктора, конструктора копирования и копирующего оператора присваивания
- Правило 0 - ничего из вышеперечисленного писать нельзя, лучше использовать RAII-обертки для управления ресурсами, компилятор все сделает сам
```
struct C {
    ~C();                       // 5, 3
    C(const C&);                // 5, 3
    C& operator=(const C&);     // 5, 3
    C(C&&) noexcept;            // 5
    C& operator=(C&&) noexcept; // 5
};
```
Речь только про конструкторы и операторы присваивания от **экземпляров того же класса**, не про "обычные".
