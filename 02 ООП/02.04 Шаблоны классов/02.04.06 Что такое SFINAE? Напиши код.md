Substitution failure is not an error - идиома, обозначающая, что невозможность подставить шаблонные параметры в перегрузку шаблона не является ошибкой, просто данная перегрузка шаблона исключается из набора кандидатов на применение
```
// рассмотрим на примере foo(123)
template <class T> T foo(T) {} // норм перегрузка

template <class T> typename T::value_type foo(T) {} // int не класс и int::value_type не существует
template <class T> T foo(T*) {} // int это не указатель
template <class T> auto foo(T t) -> decltype(t.x) { return t.x; } // int не класс и не имеет поля x
template <class T> std::enable_if<std::is_floating_point<T>, void> foo(T) {} // std::is_floating_point<int>::value == false, поэтому шаблон не инстанцируется для int
```
