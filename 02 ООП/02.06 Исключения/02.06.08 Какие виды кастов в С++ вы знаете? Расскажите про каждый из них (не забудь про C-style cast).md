- `static_cast<Y>(x)`
    - проверяется на этапе компиляции
    - для явного преобразования типов, которые могут быть преобразованы друг к другу согласно 
        - стандарту (int к float, например)
        - определенному пользователем оператору преобразоваия X к Y - `X::operator Y();`
        - не explicit конструктору Y с параметром X - `Y::Y(X);`
    - если определены и оператор, и конструктор, то компилятор не может выбрать между ними и выдает ошибку
- dynamic_cast - для преобразования указателя/ссылки на объект полиморфного (с vtable) класса по дереву наследования
    - каст экземпляра не полиморфного класса - ошибка компиляции
    - проблема при касте указателя - nullptr
    - проблема при касте ссылки - std::bad_cast
- const_cast - для добавления или убирания cv-квалификторов
    - если объект создан константным, но закастован к неконстантному, то попытка его поменять - UB
    - если объект изначально неконстантный, но передан через константный указатель/константную ссылку, то изменение после каста к неконстантному объекту безопасно
- reinterpret_cast - для преобразования любой ссылки/указателя к любой ссылке/указателю
    - При разыменовании полученного указателя/при использовании ссылки может быть UB, если:
        - нарушено выравнивание - удрес не кратен требуемому для целевого типа
        - нарушен strict aliasing - доступ к объекту через указатель или ссылку несовместимого типа (кроме char и еще пары исключений)
- C-style cast - выбирается первый подходящий каст/комбинация среди списка:
    - const_cast
    - static_cast
    - static_cast + const_cast
    - reinterpret_cast
    - reinterpret_cast + const_cast
