Run-Time Type Information - механизм получения данных о типе объекта во время выполнения через `typeid` и `dynamic_cast`. Доступно только для полиморфных классов (с виртуальными функциями)
```
struct Base { virtual ~Base() = default; };
struct Derived : Base {};

int x;
Base* bp = new Derived;

// информация доступна еще на стадии компиляции
std::cout << "not RTTI: " << typeid(x).name();
float y = static_cast<float>(x);

// информация доступна только в рантайме, получаем ее с помощью RTTI
std::cout << "RTTI:" << typeid(*bp).name();
Derived* dp = dynamic_cast<Derived*>(bp);
```
