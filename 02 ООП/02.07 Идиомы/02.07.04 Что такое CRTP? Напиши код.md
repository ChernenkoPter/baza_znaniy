Curiously Recurring Template Pattern - класс-наследник преедает себя в качестве шаблонного параметра базовому классу. Используется для реализации возможностей динамического полиморфизма средствами статического полимофризма.
```
template<typename T>
struct Base { void foo() { static_cast<T*>(this)->bar(); } };
struct Derived : Base<Derived> { void bar() {} };
```
