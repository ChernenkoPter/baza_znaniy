Считаем, что вместимость равна 100. При попытке добавить 101 будет переаллокация - выделение нового куска памяти размером 200, перемещение или копирование (если перемещение не noexcept) старых 100 элементов, уничтожение старых элементов и освобождение старой памяти, добавление 101 элемента. После операции size == 101, capacity >= 101. Все итераторы, ссылки и указатели на элементы вектора инвалидируются
При удалении элемента переаллокации не происходит, просто вызывается деструктор для 101 объекта, размер уменьшается до 100, итераторы на 101 элемент инвалидируются
