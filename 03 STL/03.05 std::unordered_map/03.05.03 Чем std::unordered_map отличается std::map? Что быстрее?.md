Структура данных под капотом определяет:
- сложность вставки, удаления и поиска, на практике у unordered_map они часто быстрее
- требования к ключу:
  - наличие hash и == у unordered_map
  - наличие < у map
- map упорядочен
- итераторы map инвалидируются только при удалении соответствующего элемента, у unordered_map - при рехеше инвалидируются все
