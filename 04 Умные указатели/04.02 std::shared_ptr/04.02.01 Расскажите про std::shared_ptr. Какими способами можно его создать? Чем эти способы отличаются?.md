Это умный указатель, который реализует владение объектом множеством указателей. 
- `std::make_shared<T>(args)` - тогда контрольный блок и объект выделяются в одном блоке памяти, но нельзя указать deleter для объекта
- `std::allocate_shared<T>(alloc, args)` - тогда память под контрольный блок и объект выделяется и освобождается через аллокатор вместо new/delete, но нельзя указать deleter для объекта
- `std::make_shared_for_overwrite<T>(args)`, `std::allocate_shared_for_overwrite<T>(alloc, args)` - создать объект с дефолтным значением, потому что его все равно собираются менять, с 20 стандарта
- все вышеперечисленые функции с шаблонным параметром T, который является массивом, и аргументом типа size_t - для создания массива 
- `std::shared_ptr<T> p(new T, Deleter{}, Alloc{})` - можно указать deleter и аллокатор, но если объект будет создан, а потом произойдет исключение, то его память утечет
- `std::shared_ptr p = shared_p;` - создать еще один указатель на объект, увеличивает счетчик ссылок
- `std::shared_ptr p = weak_p.lock();` - создать еще один указатель на объект, если он жив, иначе nullptr
- `std::shared_ptr p = std::move(unique_p);` - передать владение объектом, unique_p становится nullptr
- `std::shared_ptr p;` - создать с nullptr, контрольный блок не создается
