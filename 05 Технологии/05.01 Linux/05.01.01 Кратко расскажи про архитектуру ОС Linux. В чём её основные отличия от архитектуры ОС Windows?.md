Линукс состоит из kernel space и user space. Пользователь взаимодействует с user space, оно с помощью syscall взаимодействует с kernel space, kernel space взаимодействует с железом. В kernel space находится монолитное ядро, в котором все компоненты ядра (встроенные и загружаемые `.ko`) имеют общее адресное пространство. Благодаря этому нет накладных расходов на переключение контекста и передачу информации между компонентами, но при ошибке в одной компоненте падает вся система. Можно сравнить это с динамическими либами и исполняемым файлом.
При использовании архитектуры микроядра из kernel space оставляют микроядро - планировщик, управление памятью и IPC; драйвера, файловые системы и сетевые стеки выносят в user space. В Windows используется архитектура гибридного ядра - часть сервисов оставлены в kernel space для производительности. В отличие от линукс при вызовах между компонентами проверяются объекты и права доступа, за счет чего такие взаимодействия работают медленнее, но устойчивее к ошибкам драйверов
