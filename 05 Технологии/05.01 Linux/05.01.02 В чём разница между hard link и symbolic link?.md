- жесткая ссылка - указывает на inode файла, нельзя создать жесткую ссылку на директорию и на файл в другой файловой системе. Если на inode не осталось жестких ссылок и файл не открыт ни одним процессом - файл удаляется
- мягкая ссылка - отдельный inode, содержит путь к целевому файлу. Может быть битой, если по указанному пути файл отсутствует
