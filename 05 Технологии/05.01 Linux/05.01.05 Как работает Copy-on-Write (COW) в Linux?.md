Это оптимизация: вместо того чтобы копировать все данные для совместной работы, система дает обеим сторонам общий доступ на чтение. Когда какая-то сторона хочет изменить часть данных - копируются только эти данные для стороны, которая пишет.
Самый частый пример - fork + exec. При fork родитель и потомок делят read-only страницы. Если вызывается exec - замена образа процесса, страницы старого образа выбрасываются, т.е. при форке не произошло лишнего копирования. Если страницы пытаются менять, создается копия только той страницы, которую меняют
