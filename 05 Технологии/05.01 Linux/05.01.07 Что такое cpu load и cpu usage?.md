- сpu load - среднее количество процессов в очереди на выполнение (в т.ч. ожидающие I/O) за последние 1/5/15 минут
- cpu usage - процент времени, в течение которого он был занят пользовательскими процессами (us), системными процессами (sy), процессами с не дефолтным nice-приоритетом (ni), простаивал (id - idle), ждал I/O (wa - wait), обрабатывая аппаратные прерывания (hi), программные прерывания (si) и сколько времени украдено у данной виртуальной машины гипервизором (st)
