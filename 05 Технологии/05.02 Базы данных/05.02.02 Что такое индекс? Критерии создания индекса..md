Индекс - структура, которая ускоряет select по индексируемым колонкам таблицы, обычно реализуется как b-tree, хранящее ключ и указатель на строку. Порядок столбцов в индексе важен. У таблицы может быть несколько индексов. Каждый индекс замедляет update, insert, delete, т.к. индекс требуется перестраивать. Оптимизатор сам решает пользоваться индексом или нет.
Создается пользователем, когда выполняются следующие критерии:
- в таблицу мало пишут, но из нее много читают, сама таблица большая
- колонки часто в  where, join on, order by и group by
- у индексируемых столбцов много уникальных значений относительно числа строк
