Это сохранение результатов операций, которые повторяются и их результат не меняется между вызовами. Ускоряет получение ответа и разгружает базу/усеньшает чтение с диска. Сохранять можно:
- buffer pool - страницы таблиц/индексов в оперативной памяти вместо чтения с диска
- materialized view - view, записанный на диск, в отличие от обычного view не надо строить каждый раз заново
- внешний кеш - результаты запросов
У всех кешей есть проблема с синхронизацией данных в кеше и на диске, они решаются с помощью разных стратегий записи (write-through, write-behind) и удаления (инвалидация по ключу или по TTL)
